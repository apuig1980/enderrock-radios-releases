# Enderrock Ràdios · descàrregues

Aquest repositori només conté les versions compilades de l'aplicació **Enderrock Ràdios** per a Mac (Apple Silicon).
L'aplicació comprova aquí si hi ha versions noves des de *Configuració → Actualitzacions*.

- `version.json`: darrera versió publicada.
- `versiones/`: paquets d'actualització (sense base de dades; les dades de l'usuari no es toquen).
